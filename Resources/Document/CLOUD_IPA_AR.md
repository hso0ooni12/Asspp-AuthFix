# تنزيل Tahakom من الآيفون عبر GitHub Codespaces

هذا المسار مستقل عن تنزيل Asspp الذي يرجع HTTP 403، ويستخدم أداة
[ipatool الرسمية](https://github.com/majd/ipatool) بإصدار 2.7.0 على لينكس سحابي.

## الخطوات

1. افتح [إنشاء Codespace للمشروع](https://codespaces.new/hso0ooni12/Asspp-AuthFix?quickstart=1) من سفاري وسجّل دخولك إلى GitHub.
2. انتظر حتى تفتح واجهة VS Code في المتصفح ويكتمل تجهيز البيئة.
3. افتح **Terminal → New Terminal**. في الآيفون قد تحتاج خيار **طلب موقع سطح المكتب**.
4. نفّذ الأمر الآتي:

   ```bash
   bash Resources/Scripts/cloud-download-tahakom.sh
   ```

5. إذا طلبت الأداة تسجيل حساب أبل، أدخل حسابك السعودي ورمز التحقق داخل الطرفية فقط. وقد تطلب عبارة مرور منفصلة لحماية بيانات الجلسة.
6. بعد ظهور رسالة النجاح، افتح مجلد `cloud-downloads` من مستكشف الملفات، واختر **Download** لملف `Tahakom-5.0.2-encrypted.ipa`.
7. بعد حفظ الملف والتأكد منه، احذف Codespace من [صفحة Codespaces](https://github.com/codespaces) إذا ما تحتاجه؛ الحذف يزيل بيئة العمل وبيانات الجلسة المحفوظة فيها.

**تنبيهات مهمة:**

- Codespaces قد يستخدم من حصتك المجانية أو يترتب عليه رسوم حسب حساب GitHub.
- لا تضع كلمة المرور أو رمز التحقق في رسالة، أو Issue، أو GitHub Secret خاص بهذا المشروع؛ الأداة تتعامل مع تسجيل الدخول بشكل تفاعلي.
- هذا المسار ما زال يحتاج اختبارًا بحساب سعودي حقيقي. نجاح إعداد البيئة لا يضمن استجابة أبل للتنزيل.
- الملف الناتج **مشفّر بتقنية FairPlay**؛ حفظه بصيغة IPA لا يعني فك تشفيره. فك التشفير خطوة أخرى منفصلة.
- الإصدار محدد عمدًا على **5.0.2** ومعرف النسخة **894501944**. إذا صدر تحديث جديد، يحتاج السكربت إلى تحديث.
